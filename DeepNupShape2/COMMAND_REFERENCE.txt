# Command Reference Card - DeepNup Shape Integration

## Three Essential Commands

### 1. PREPROCESS DATA
```powershell
python Data_encoded_with_shapes.py -p "Dataset\Sequence" -sp "Dataset\Shape" -f "nucleosomes_vs_linkers_melanogaster.fas" -o "encoded_shapes"
```
**Output:** 6 pickle files (one_hot, PseTNC, shape for nuc & link)
**Time:** 2-5 minutes
**Status:** ✓ Run once

---

### 2. TRAIN MODEL
```powershell
# Original model (DEFAULT - FAST)
python training_with_shapes.py -p "encoded_shapes" -o "results_original" -e "Mel_Original"

# MLSNet model (ADVANCED - ACCURATE)
# First: Edit training_with_shapes.py line 18
# Change: from model_dn_with_shapes import dn_with_shapes
# To: from model_dn_with_shapes_mlsnet import dn_with_shapes_mlsnet as dn_with_shapes
python training_with_shapes.py -p "encoded_shapes" -o "results_mlsnet" -e "Mel_MLSNet"
```
**Output:** 3 trained models (one per fold)
**Time:** 20-30 min (original) or 30-40 min (MLSNet)
**GPU Memory:** 300-500 MB (original) or 600-800 MB (MLSNet)

---

### 3. EVALUATE RESULTS
```powershell
# Original model
python predict_with_shapes_best_model.py -p "encoded_shapes" -m "results_original" -e "Mel_Original" -f 1

# MLSNet model
python predict_with_shapes_best_model.py -p "encoded_shapes" -m "results_mlsnet" -e "Mel_MLSNet" -f 1
```
**Output:** Metrics + PNG chart + TXT results
**Time:** 3-5 minutes
**Expected AUC:** 0.78-0.82

## Troubleshooting

### Data not found
```powershell
# Verify data exists:
dir "Dataset\Sequence\nucleosomes_vs_linkers_melanogaster.fas"
dir "Dataset\Shape\nucleosomes_vs_linkers_melanogaster.fas.*"
```

### Out of GPU memory
```powershell
# Reduce batch size in training_with_shapes.py line ~80:
batch_size = 32  # Instead of 64
# Or: batch_size = 16
```

### Model file not found
```powershell
# Check training completed:
dir "results_original\Mel_Original\models\dn_shape\*.keras"
# Should show 3 files (fold1, fold2, fold3)
```

### Training too slow
```powershell
# MLSNet is naturally slower (35-40 min/fold)
# Original should be ~20 min/fold
# CPU training: double these times
```

## Parameter Meanings

```powershell
# Data encoding parameters:
-p "Dataset\Sequence"           # Path to FASTA file directory
-sp "Dataset\Shape"             # Path to shape files directory
-f "nucleosomes_vs_linkers_..."  # FASTA filename
-o "encoded_shapes"             # Output directory for pickles

# Training parameters:
-p "encoded_shapes"             # Input: Pickle files directory
-o "results_original"           # Output: Models directory
-e "Mel_Original"               # Experiment name (folder prefix)

# Evaluation parameters:
-p "encoded_shapes"             # Input: Pickle files for full dataset
-m "results_original"           # Input: Models directory
-e "Mel_Original"               # Experiment name (matches training -e)
-f 1                            # Which fold model to use (1, 2, or 3)
-pn "DeepNup Original"          # Plot title
```
